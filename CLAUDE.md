# Правила работы с репозиторием

Репозиторий содержит модели Archi (`.archimate`) по проектам и их выгрузки.

## Представления схем — обязательный PDF

Любое изменение представления (View) в любой модели обязано сопровождаться
обновлением PDF-представления **в том же коммите**.

Основной способ выгрузки — сам Archi (картинка ровно как в редакторе),
нужны Archi 5.x и плагин jArchi 1.7+:

```bash
tools/archi_export_views.sh                # выгрузка всех представлений силами Archi
```

Резервный способ, когда Archi недоступен (CI, чужая машина) — встроенный рендер:

```bash
python3 tools/archi_export_pdf.py          # перегенерировать все представления
python3 tools/archi_export_pdf.py --check  # проверить актуальность (код 1 — расхождение)
```

На сервере это делает и CI: workflow «Представления схем (PDF)» выгружает
представления силами Archi и коммитит их в ту же ветку
(`.github/workflows/pdf-representations.yml`).

PDF лежит в папке проекта и называется `<проект>_<имя представления>.pdf`.
PDF руками не правят: источник истины — `.archimate`.
Реестр выгрузок — `pdf-представления.json`, его обновляют инструменты.
Полный регламент: [docs/05-Правило-PDF-представлений.md](docs/05-Правило-PDF-представлений.md).
