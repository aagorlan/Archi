# Реестр схем Archi: разделение по описываемым состояниям

Репозиторий содержит **15 файлов `.archimate`** (14 из них — ZIP-контейнеры с `model.xml`
внутри, `Jira`, `SRM v4` и `Единые сервисы` — plain XML) и **32 схемы (View)**.

Классификация выполнена по содержанию схем, а не только по названию: учитывались
состав ИС, наличие платформ `TBD`, элементы-легенды («Целевая ИС», «Требуется выбор
платформы»), а также номера функций `F*` и потоков `DF*`, которые проставляются только
на проектируемых состояниях.

## C. ПЕРЕХОДНОЕ состояние (этапы MVP / миграция) — 5 схем

Это не «текущее» и не «конечное целевое», а фиксация промежуточного шага.

| Модель | Схема (View) | Объектов / связей | Суть этапа |
|---|---|---|---|
| CRM | **MVP** | 79 / 81 | Первая очередь выноса из ERP в `Сопровождение маркетинга`: Лиды, Сделки, Аккаунты, Обращения, НСИ Продаж |
| CRM | **Маркетинг (пред MVP)** | 27 / 21 | Шаг до MVP: `Управление маркетингом` + мобильное приложение + `Управление опросами` (TBD) |
| QMS | **MVP** | 36 / 31 | Только входной контроль (IQC) и НСИ качества; рекламации ещё в `ERP (Ядро)` |
| Архив | **Первый этап (MVP)** | 26 / 18 | Только `Долгосрочное хранилище` + загрузка из Диадок и потокового сканера |
| Командировки | **Переход на TRIVIO** | 38 / 44 | Оба провайдера бронирования одновременно: `Corteos` (LAN) и `TRIVIO` (Internet) |

## D. Сравнительные, процессные и справочные схемы — 7 схем

Не описывают одно состояние ландшафта целиком.

| Модель | Схема (View) | Тип | Комментарий |
|---|---|---|---|
| QMS | **Изменение работы** | AS-IS vs TO-BE на одном листе | Две группы: `Текущее` (входной контроль в `MES FA` + почта) и `Целевое` (QMS → WMS → ERP) |
| RPA | **Процесс развертывания робота** | бизнес-процесс | Только Business-слой, ИС не показаны |
| Архив | **Обработка документов** | бизнес-процесс | Жизненный цикл документа, ИС — только `Диадок` и обобщённая «Учетная система» |
| Мониторинг | **Процессы** | матрица покрытия | 3 группы (Hardware / Информационные ресурсы / Software) × процессы; ИС указана в свойстве `Platform`. **Связей нет вообще** |
| Разделение ERP | **Организационная схема** | распределение ответственности | ИС → департамент-владелец |
| Склады | **География** | срез TO-BE по площадкам | 5 площадок + виртуальные склады → целевые системы |
| Склады | **География (copy)** | **дубликат** | Полная копия предыдущей, отличается только наличием блока легенды. **Кандидат на удаление** |
| Мобильная платформа | **Default View** | референсная архитектура | Шаблон: `Мобильное приложение` ↔ `Шлюз` (DMZ) ↔ `Сервер МП` ↔ ИС. Состояние не привязано |
| Единые сервисы | **Адресные книги**, **Календари** | AS-IS инфраструктуры | Как сейчас синхронизируются два домена `yadro.com` и `1440.space` |
| Единые сервисы | **Сервисы** | референсный паттерн | Обезличенный шаблон публикации сервиса (`x.y.com`, Split DNS) |
